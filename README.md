# KAI / EDITS — Video Editor Portfolio

A responsive portfolio website inspired by the supplied screenshots.

## Files
- `index.html` — page structure and project content
- `style.css` — responsive styling
- `script.js` — category filters, video modal, mobile navigation, and contact form behavior

## Run locally
Open `index.html` in a browser. For best results, use a local development server such as VS Code Live Server.

## Before publishing
1. Replace the sample project names, dates, descriptions, and video embed URLs with your real work.
2. Replace the stock image URLs with stills/thumbnails from your own edits.
3. Update `hello@kaiedits.co` and the WhatsApp URL in `index.html`.
4. The contact form currently opens the visitor's email app using `mailto:`. For a form that sends directly without requiring an email app, connect it to Formspree, Web3Forms, or a backend.
5. Use only video footage, music, and images you have permission to publish.

The sample video URLs are demo embeds and should be replaced with your own YouTube/Vimeo embed links.
